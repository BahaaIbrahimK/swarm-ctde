#  Regenerated 2026-11-19 for transfer to a second machine.

#
#  WHY THIS FILE EXISTS ALONGSIDE requirements.lock.txt
#  ----------------------------------------------------
#  The original lock had two properties that break a fresh install:
#
#   1. IT PINNED THE CUDA BUILD OF PYTORCH (torch==2.13.0+cu130 plus 19
#      nvidia-* packages, ~2.5 GB). This project NEVER uses a GPU --
#      torch.cuda.is_available() is False on the machine that produced every
#      result, and the training code runs with device="cpu". On a laptop with
#      no NVIDIA card those wheels are useless and may refuse to install.
#
#   2. IT USED AN EDITABLE INSTALL AT A HARDCODED PATH
#      (-e git+...#egg=gym_pybullet_drones, cloned to ~/gym-pybullet-drones).
#      A different username makes that path wrong.
#
#  This file pins the SAME versions with the CUDA stack removed, and installs
#  gym-pybullet-drones non-editable directly from its exact commit.
#
#  PHYSICS DEPENDS ON THAT COMMIT. gym-pybullet-drones is not on PyPI, and its
#  downwash model and BaseAviary.step() ordering both changed between commits.
#  Pinning the commit is not housekeeping -- a different commit means different
#  numbers.
#
#  INSTALL -- use setup_new_machine.sh instead of running this by hand.
#      python3.12 -m venv .venv
#      source .venv/bin/activate
#      pip install --index-url https://download.pytorch.org/whl/cpu torch==2.13.0
#      pip install -r requirements.cpu.txt
# =============================================================================
